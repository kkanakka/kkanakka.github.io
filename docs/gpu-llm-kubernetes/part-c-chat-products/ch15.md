## Things that look simple and aren't

<ul>
<li><strong>Stop button</strong>: the client aborts the HTTP request; the server must propagate cancellation to the engine so KV blocks are freed immediately, and persist the partial reply.</li>
<li><strong>Edit a message</strong>: creates a sibling branch under the same parent. The UI shows "2/3" arrows; the DB keeps all branches.</li>
<li><strong>Reconnect mid-stream</strong>: the server buffers the in-flight response in Redis keyed by request ID so a client that drops and reconnects can resume from the last offset.</li>
<li><strong>Latency perception</strong>: showing a "thinking…" indicator, streaming the first token within ~500 ms, and rendering code blocks progressively matter more to perceived speed than raw tokens/sec.</li>
<li><strong>Extended thinking</strong>: models that reason before answering emit a separate "thinking" block; the UI may show it collapsed, and the server may summarize or redact it.</li>
</ul>
