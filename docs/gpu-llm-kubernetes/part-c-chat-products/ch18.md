## Constitutional AI, briefly

<ol>
<li>Write a "constitution": a set of natural-language principles (be helpful, avoid harm, be honest, respect autonomy…).</li>
<li>Have the model generate responses, then critique and revise its own responses against those principles (supervised phase).</li>
<li>Generate pairs of responses and have the model judge which better follows the principles, producing a preference dataset without human raters for most comparisons.</li>
<li>Train a preference model on that data; use it as the reward for RL (RLAIF), alongside human feedback for helpfulness.</li>
</ol>
<p>The result is a model whose behavior is traceable to written principles rather than to an opaque pile of human ratings — and a document that can be published and debated.</p>

## How a request to Claude is priced and metered

<ul>
<li>Input tokens (uncached), cached input tokens (much cheaper — a cache read), cache writes (slightly more than uncached input), and output tokens, each with a per-model price.</li>
<li>Tool definitions, tool results and thinking tokens all count. Images count by pixel area.</li>
<li>Batch API: asynchronous, ~50% discount, results within 24 h — soaks up spare GPU capacity.</li>
<li>Rate limits by tier: requests/minute and input/output tokens/minute, raised with spend history.</li>
</ul>
