## Final-week checklist & resources

<p>

<h3>Logistics</h3>
<ul>
<li>Practice in Replit/Colab/CodeSignal — no local IDE, no autocomplete, no AI assistance.</li>
<li>CodeSignal: read all visible levels first; design L1 so L2–4 are extensions, not rewrites; keep a 10-minute buffer — running out of time is the most reported failure.</li>
<li>System design is in a shared Google Doc: practice a doc structure (Requirements / Estimates / Architecture / Deep dives / Failure modes / Metrics) instead of drawing boxes.</li>
<li>Prepare 3–4 questions per interviewer about the team's real problems (how they canary model rollouts; their worst recurring incident class).</li>
</ul>
<h3>Reading list (a few hours)</h3>
<ul>
<li>vLLM blog: PagedAttention + continuous batching — the highest-ROI read for this loop.</li>
<li>Orca (OSDI '22) summary; NVIDIA/HF posts on LLM inference performance for TTFT/TPOT intuition.</li>
<li>Google SRE book: SLOs, error budgets, load shedding, cascading failures.</li>
<li>Anthropic: Core Views on AI Safety, the Responsible Scaling Policy, and 1–2 recent engineering posts.</li>
</ul>
